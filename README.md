React Quiz Website
==================

A simple and interactive quiz website built with React, Vite, Redux, and normal CSS. 
The app presents 20 multiple-choice questions and shows the final score at the end.

-----------------------------------------
🚀 Features
-----------------------------------------
- 20 multiple-choice quiz questions
- Score tracking
- Answer feedback (correct/incorrect)
- Final results summary
- State management using Redux
- Clean and responsive UI with plain CSS
- Built using Vite for fast development and build time

-----------------------------------------
🛠 Tech Stack
-----------------------------------------
- React
- Vite
- Redux (with Redux Toolkit)
- JavaScript
- CSS
-----------------------------------------
📦 Installation
-----------------------------------------
1. Clone the repository
   git clone https://github.com/ayhamdw/react-quiz.git

2. Navigate into the project folder
   cd react-quiz

3. Install dependencies
   npm install

4. Run the development server
   npm run dev

5. Build for production
   npm run build

-----------------------------------------
📄 Data Format (Sample Question)
-----------------------------------------
{
  question: "What is the capital of France?",
  options: ["Berlin", "Madrid", "Paris", "Rome"],
  correctAnswer: "Paris"
}

-----------------------------------------
📌 Notes
-----------------------------------------
- You can customize the questions by editing the data in the ./data/questions.js (or .json) file.
- State management is handled via Redux for scalability and maintainability.
- Styling is done using plain CSS for simplicity, but feel free to integrate Tailwind, SASS, or CSS modules.
